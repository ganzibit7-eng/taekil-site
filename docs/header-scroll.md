# 상단 스크롤 보완 — 2026-11-10

기존 sticky top 14px(작은 화면 8px) 간격을 제거하고 top 0으로 통일했다. 헤더의 전체 화면 너비 배경을 불투명하게 채워 양옆과 위쪽으로 스크롤 콘텐츠가 비치지 않게 했다. 기존 상담 모드의 별도 visual viewport 배치와 메뉴·로그인 스크립트는 변경하지 않았다. safe-area 상단 여백은 내부 padding으로 적용한다.

실제 브라우저: PC 스크롤 전후 및 390px 모바일 스크롤에서 헤더 top 0px, 가로 넘침 없음. 원본 기능·68개 상세 보존 검사 및 관리자 통계 검사 통과. 신년상담 서버의 기존 미커밋 작업은 별도로 보존했다.
