## 채택한 방향

무료 답변으로 연우의 상담 품질을 확인한 뒤, 남은 질문을 이어가는 소액 질문권과 상담·정밀 택일을 함께 이용하는 기간형 상품으로 나눕니다. 질문 1개 가격이나 리포트 글자 수만을 주된 가치로 내세우지 않습니다.

- 질문 5개 1,900원: 지금의 고민을 더 묻는 첫 구매.
- 질문 10개 3,200원: 상담 질문만 더 필요한 이용자.
- 프리미엄 30일 8,900원: AI 하루 10개 질문, 최대 365일 후보 중 TOP 20, 궁합 택일·월별 날짜·상세 리포트.
- 무료 계정당 총 3개 질문, 무료 택일 30일/TOP 5 유지.
- 실제 청구 가격·상품 ID·결제 처리·회원 이용권·무료 횟수는 변경하지 않음.

가격 인하나 신규 고가 리포트 판매는 보류합니다. 현재 초기 결제 13건·33,200원은 운영자 테스트이므로 실제 지불 의사나 전환율의 근거로 삼지 않습니다. Claude 실제 원가, 페이앱 수수료, 환불, 유료 이용자의 사용량을 확인하기 전 무제한·대량 질문권을 신설하지 않습니다.

## 결제 화면 변경

기존에는 무료와 프리미엄 카드 아래에 질문권이 작게 붙어 있어 차이를 비교하기 어려웠습니다. 이제 상담 전용과 상담+정밀 택일을 나란히 배치하고, 실제 금액이 적힌 버튼으로 구매합니다. 취소선 가격과 확인 근거가 없는 추천 배지는 화면에서 숨겼습니다. 결제일 기준 30일, 하루 10개 한도, 자동갱신 없음, 로그인한 계정으로 지급됨을 구매 전에 확인할 수 있습니다. 기존 환불 약관·문의 동선으로 연결합니다.

페이앱이 제공하는 외부 결제창 자체는 변경하지 않았습니다. 실제 결제를 발생시키는 검증은 수행하지 않습니다.

### 신규 결제 일시 중단 및 재개

운영 Firebase의 Firestore 문서 `siteSettings/checkout`에서 불리언 `enabled`를 `true`로 저장하면 프리미엄과 질문권 판매가 재개됩니다. `false`이거나 문서가 없으면 주문 생성이 차단됩니다. 운영 Firebase 콘솔에서 설정만 바꾸면 됩니다. 기존 주문 조회와 페이앱 승인 처리에는 이 설정을 적용하지 않습니다.

## 적용한 관리자 기능

오늘/최근 7일/30일/90일 선택, 방문·가입의 이전 동일 기간 비교, 완료 주문 금액·건수·평균 결제액, 방문/금액 차트 전환, 접근성 있는 일별 수치 표, 상품별 결제 표, 유입 경로 막대, 상담 관련 행동, 가이드별 성과, 개인정보 없는 일별 CSV, 조회 시각·오류·부분 집계 표시를 제공합니다. 기존 회원·문의·밴·실시간 통계 기능은 보존합니다.

기존 관리자 전용 CSS가 실제 main 요소를 숨겨 관리자 화면이 비어 보이는 문제도 수정했습니다.

## 집계의 한계와 정확성

기간 매출은 paymentOrders의 status=paid 주문만 합산하며, 테스트 포함·환불/수수료 차감 전 금액입니다. 결제일이 있으면 사용하고 없으면 주문 생성일을 사용합니다. 생성일이 없는 과거 주문은 기간별 조회에 빠질 수 있습니다. 최근 최대 1,000개 주문 기준이며 초과 시 부분 집계임을 표시합니다. 가이드는 최대 2,000개 문서입니다.

운영자가 확인한 초기 테스트 13건·33,200원은 stats/counters 누적 수치에서 한 번 제외한 별도 참고값으로만 표시합니다. 거래 ID를 확인하지 않은 상태에서 날짜별·상품별 주문을 임의로 제외하지 않습니다. 원장과 원본 카운터를 수정하지 않습니다. 이 보정은 거래별 테스트 식별이나 회계상 순매출이 아닙니다.

기존 일별 행동은 서로 독립적인 집계입니다. 동일 이용자의 순차 전환을 증명하지 못하므로 이전 단계 대비 전환율과 자동 이탈 구간 표시는 숨기고 독립 행동 건수로 안내합니다. 가입/첫 답변/결제 이벤트와 실제 주문 건수는 수집 기준이 달라 차이가 날 수 있습니다.

조회 실패를 0으로 표시하지 않습니다. 조회에 성공했지만 일별 문서가 없는 날짜는 0으로 표시하며 미수집/수집 시작 전 날짜를 따로 구분할 수 없다는 점을 안내합니다. 모든 분석 조회는 기존 관리자 인증과 Firestore 권한 안에서 읽기만 수행합니다.

## 배포 후 실제 기록 대조 보완

기존 저장 로그인 복원 뒤 관리자 화면이 갱신되도록 기존 화면 렌더러 연결을 보완했습니다. 초기 관리자 전용 스타일과 경로 전환도 함께 정리했습니다. 완료 주문에 저장된 요청 금액과 누적 결제 카운터의 차이를 탐지해 나란히 표시합니다. 과거 주문 저장 금액이 실제 결제 금액과 일치한다는 보장이 없으므로 기간별 금액을 실제 매출로 확정해 표시하지 않습니다. 검색 가이드는 기존 YYYY-MM-DD__slug 문서 ID 범위를 사용하고, 조회 권한·인덱스·연결 오류를 구분해 안내합니다.

검색 가이드의 기존 클라이언트 읽기 권한이 차단되어, 같은 관리자 계정의 검증된 Firebase 토큰으로 집계값만 읽는 서버 경로를 추가했습니다. 이 경로는 날짜·가이드명·횟수만 반환하고 회원 정보·상담 내용은 응답하지 않으며, 기존 Firestore 규칙과 결제·상담 API는 수정하지 않습니다.
