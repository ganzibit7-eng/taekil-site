# 상담 화면과 페이지 전환 개선

2026-11-10

기존에는 생년월일 입력을 영상 아래 240px, 채팅을 140px 아래로 배치해 단계가 바뀔 때 페이지 높이와 스크롤 위치가 달라졌습니다. 이제 상담 단계에서는 같은 크기의 영상 화면을 유지하고 입력과 대화를 그 안에서 전환합니다.

- 기존 연우 영상 파일·프로필을 그대로 사용합니다.
- 입력 항목과 긴 답변만 내부에서 스크롤합니다. 입력 확인 버튼과 메시지 작성창은 아래에 유지합니다.
- 모바일의 보이는 화면 높이 변경을 반영하고, 상담 화면에 홈으로 돌아가는 버튼을 추가했습니다.
- 일반 페이지 이동은 기존 위치를 이어받지 않고 위쪽부터 즉시 표시합니다. CSS의 자동 부드러운 스크롤과 페이지 교체 시 스크롤 앵커링을 끕니다.
- 아래 콘텐츠 더 보기·가이드 등 사용자가 의도한 화면 내 이동은 기존 동작을 유지합니다.
- 로그인, 사주 저장, Claude 호출, 결제, 이용권 및 무료 횟수의 기존 스크립트와 이벤트 연결은 변경하지 않았습니다.

## 배포 전 화면 검증

실제 페이지 구조에서 서버/API를 호출하지 않는 검증 화면을 별도로 사용했습니다. 검증 화면은 배포에 포함하지 않습니다.

| 화면 | 페이지 스크롤 | 문서 높이 | 작성창/확인 버튼 아래 좌표 |
|---|---:|---:|---:|
| 360 × 800 | 0 | 800 | 784 |
| 393 × 852 | 0 | 852 | 836 |
| 393 × 450 | 0 | 450 | 434 |
| 768 × 1024 | 0 | 1024 | 1008 |
| 1440 × 1000 | 0 | 1000 | 984 |

입력 → 채팅 전환 전후에도 영상의 위치와 높이를 유지했습니다. 이용권 안내 → 날짜 찾기 이동도 스크롤 0에서 바로 표시됩니다. 393×450은 화면 높이를 줄인 검증이며 실물 iPhone/Android 키보드 검증을 대신하지 않습니다.

기존 기능 보존 검사, 68개 상세 페이지 내용·링크·스크립트 보존 검사, 추가 화면 스크립트 구문 검사를 통과했습니다. 운영 배포 후 실제 관리자 계정의 저장된 가상 사주로 연결을 다시 확인합니다.
